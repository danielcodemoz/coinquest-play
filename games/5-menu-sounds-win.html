Level 5 Menu, Sounds & Win Screen

What you are learning

A finished game has more than one scene: a Menu, the Game, and a Win or Game Over screen. Sounds make every action feel good. Everything here, art and audio, is generated by code.

Scenes (events)

  • ConditionMenu scene: Start button clicked (or Enter pressed)
    ActionChange scene to “Game”
  • ConditionGame scene: Jump key pressed / coin collected / Player hurt
    ActionPlay sound · Play music at scene start
  • ConditionPlayer collides with Flag
    ActionAdd time bonus · Change scene to “Win” (Score stays in a global variable)
  • ConditionLives ≤ 0 OR TimeLeft ≤ 0
    ActionChange scene to “Game Over”

Variables

The variable scene here stands for “which scene is running”. In GDevelop, global variables keep the Score alive when you change scenes.

Your turn in GDevelop

  • Make 3 scenes: Menu, Game, Win. Add a button sprite and a click/touch event.
  • Add sounds with the action “Play a sound” (jump, coin, hurt, win).
  • Loop a music track with “Play a music”; add a Sound on/off button.
  • Show stars: 1 for winning, +1 all coins, +1 no lives lost.
