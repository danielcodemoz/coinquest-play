Level 2 Coins & Score

What you are learning

A variable is a named box that remembers a value. Here Score goes up by 10 every time a coin is collected.

Events

  • ConditionPlayer collides with Coin
    ActionDelete Coin · Play coin sound
  • ConditionSame event, next action
    ActionAdd 10 to variable Score
  • ConditionNumber of Coin objects = 0
    ActionShow the win message

Variables

Score is a number you change with the action “Add to a variable”. coinsLeft is the object count of Coin — GDevelop can count objects for you.

Your turn in GDevelop

  • Create a scene variable Score = 0.
  • Add a Coin sprite and copy it around the level.
  • Event: Player collides with Coin → Delete Coin, add 10 to Score, play a sound.
  • Show it with a Text object: "Score: " + ToString(Variable(Score))
  • Bonus: give golden coins an object variable value = 50.
